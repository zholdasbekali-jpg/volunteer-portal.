# Жол картасы (тарихи жоспар)

> Бұл файл — бастапқы жоспардың тарихи көшірмесі. Ондағы v2.0 “әзірлеуде” күйі мен қараша/желтоқсан күндері қазіргі release күйін білдірмейді. Қолданыстағы функцияларды `README.md` пен `CHANGELOG.md` қараңыз.

| Жоспар кезеңі | Мақсат | Тарихи нәтиже |
|---|---|---|
| v1.0 | Алғашқы жеткізу | Каталог, рөлдер, тіркелімдер, PDF-сертификаттар, статистика |
| v1.1 | QR арқылы check-in | Динамикалық қолтаңбалы QR |
| v2.0 | Профиль және іздеу | Volunteer ID, сағат, жетістіктер, рейтинг, санаттар, үш тіл |
| v2.1 | Қызметтерді кеңейту | Email, күту тізімі, таңдаулылар, пікірлер, ұйымдастырушыны мақұлдау, аудит, кеңейтілген статистика |

Құжатта кейінге қалған AI көмекшісі, әлеуметтік желі және марапат дүкені сияқты идеялар іске асырылған функциялар емес.
