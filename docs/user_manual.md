# Пайдаланушы нұсқаулығы

Демо-аккаунттар (`flask --app run seed-demo` арқылы жүктелгенде): әкімші `admin@volunteer.kz` / `Admin12345`; ұйымдастырушы `aigul@volunteer.kz` / `Demo12345`; ерікті `volunteer1@volunteer.kz` / `Demo12345`. Бұл тек көрсету үшін.

## Ерікті
1. **Тіркелу**: «Тіркелу» → аты-жөні, email, пароль (кемінде 8 таңба, әріп + цифр), рөл «Ерікті» → «Тіркелу». Содан кейін «Кіру».
2. **Іс-шара іздеу**: «Іс-шаралар» бетінде атауы/мекенжайы/қаласы бойынша іздеу, **қала**, күні және мәртебесі (алдағы/өткен/тоқтатылған) бойынша сүзгі. Іс-шара бетінде «Картада көру» сілтемесі мекенжайды Google Maps-та ашады (сыртқы сайт, интернет қажет). Алдағы және өткен іс-шаралар бөлек көрсетіледі.
3. **Тіркелу**: іс-шара бетінде «Іс-шараға тіркелу». Бос орын болмаса, іс-шара өтіп кетсе немесе тоқтатылса, түсінікті хабарлама шығады. Бір іс-шараға екі рет тіркелуге болмайды.
4. **Бас тарту**: «Менің тіркелімдерім» немесе іс-шара бетінде «Бас тарту» (орын босайды). Қатысу мәртебесі белгіленген тіркелімнен бас тартуға болмайды.
5. **Мәртебе**: «Расталмаған» → ұйымдастырушы белгілегеннен кейін «Қатысты» немесе «Қатыспады».
6. **Сертификат**: «Сертификаттар» бетінде тек «Қатысты» іс-шаралар көрінеді; «PDF жүктеу» басыңыз. Сертификат нөмірін `/verify/<нөмір>` арқылы кез келген адам тексере алады.

**Volunteer ID.** Ерікті кабинетінен «Volunteer ID» бетін ашады: бірегей код, сағат, жетістіктер, QR. «Профильді жасыру» батырмасы жария бетте аты-жөнін жасырады.

**Рейтинг.** Мәзірдегі «Рейтинг»: үздік еріктілер, ұйымдастырушылар, қалалар. Қатысуы белгіленген іс-шаралар ғана есептеледі.

**Іздеу.** Каталогта сөйлем жазуға болады: «экология Қызылордада осы апта». Қала, «бүгін/ертең/осы апта/осы ай» және тақырып өздігінен танылады.

**Жеке кабинет.** Жоғарғы мәзірдегі аты-жөніңізді басыңыз: профильді, құпиясөзді өзгертуге және өз көрсеткіштеріңізді (тіркелім, қатысу, сертификат; ұйымдастырушыға іс-шара мен қатысушылар; әкімшіге жалпы сан) көруге болады.

**Қатысуды QR арқылы белгілеу.** Ұйымдастырушы «Қатысушылар» бетінде «QR арқылы белгілеу» батырмасын басып, экранды көрсетеді. Ерікті сайтқа кіріп, QR-ды телефон камерасымен немесе `/verify` сканерімен оқиды да «Мен осындамын» батырмасын басады. QR әр 30 секунд сайын өзгереді. Сертификаттағы QR-кодты «Сертификатты тексеру» бетінде (`/verify`) камерамен немесе сурет жүктеп сканерлеуге болады; камера тек `https://` не `localhost` арқылы жұмыс істейді, әйтпесе сурет жүктеңіз немесе нөмірді енгізіңіз.

## Ұйымдастырушы
1. **Іс-шара құру**: «Ұйымдастырушы панелі» → «Жаңа іс-шара»: атауы, сипаттама, **қала** (тізімнен таңдалады), **мекенжайы** (көше, ғимарат), күні-уақыты (болашақта), қатысушылардың ең көп саны.
2. **Өңдеу/тоқтату/жою**: панельдегі кестеде қарындаш (өңдеу), үзіліс (тоқтату; тіркелу жабылады, қайта жариялауға болады), қоқыс (жою, растаумен). Қазіргі тіркелген санынан аз сыйымдылық қоюға болмайды.
3. **Қатысушылар**: адамдар белгішесі → тіркелген эріктілер тізімі; «Қатысты» / «Қатыспады» / «Расталмаған» батырмалары. «Қатысты»-дан шығарсаңыз, берілген сертификат жойылады.
4. **Статистика**: сандар мен 3 график тек өз іс-шараларыңыз бойынша.
Басқа ұйымдастырушының іс-шарасына қол жеткізу 403 қатесін береді.

## Әкімші
«Әкімші панелі»: платформа көрсеткіштері; «Пайдаланушылар» (рөлін өзгерту, жою; өзін өзгертуге/жоюға болмайды), «Іс-шаралар» (кез келгенін өңдеу/тоқтату/жою), «Тіркелімдер» (барлығы). «Статистика» бүкіл платформа бойынша.

## Қателер
Форма қателері беттің жоғарғы жағында қызыл хабарламамен көрсетіледі; рұқсат жоқ бетке кіргенде 403, жоқ бетке 404 беті ашылады.
