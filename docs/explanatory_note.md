# Түсіндірме жазба

## Әзірлеу кезеңдері
1. **Талдау және жобалау**: ТЗ, рөлдер, ER-диаграмма, қабатты архитектура (`technical_specification.md`, `architecture.md`, `database_design.md`).
2. **Backend**: конфиг, SQLite схемасы, сервистер (auth, event, registration, certificate, statistics), blueprints, CSRF, рөл тексеруі.
3. **Frontend**: Jinja2 шаблондары, бірыңғай CSS дизайн жүйесі, Bootstrap 5, қазақша интерфейс.
4. **Тестілеу**: 163 pytest тест — бастапқы v1.0 кезеңінің тарихи көрсеткіші. Есеп пен кейінгі тест санының түсіндірмесі `test_report.md` ішінде.
5. **Брендинг және жетілдіру**: QAMQOR дизайны (сайт, сертификат), логотип барлық беттерде, қала мен мекенжай өрістері, ескі қорларды көшіру.
6. **Құжаттама** және тірі сервердегі қолмен тексеру (скриншоттар, PDF).

## Негізгі шешімдер
- **Бизнес-логика бөлек**: маршруттар тек HTTP-мен жұмыс істейді; ережелер `services/`-те, сондықтан HTTP-сіз тестілеуге болады.
- **Орын санын қорғау**: тексеру мен INSERT бір `BEGIN IMMEDIATE` транзакциясында; ағындық тест бәсекені дәлелдейді.
- **Рөлдер сервер жағында**: `roles_required` + сервистердегі иелік тексеруі.
- **CSRF** Flask-WTF қоспай, өз шағын модулімен (ТЗ «күрделі технология қоспа» дейді).
- **Қазақ әріптері**: PDF үшін DejaVu Sans қарпі жобаға енгізілген; іздеу үшін Юникод `PYLOWER`.
- **Офлайн**: Bootstrap мен иконкалар локалды (`static/vendor`).

## Қиындықтар
- SQLite `LOWER()` кириллицада жұмыс істемейді: тест ашты, `PYLOWER` арқылы шешілді.
- Графиктердің бірыңғай көрінісі (легенда, бүтін осьтер): скриншот арқылы тексеріліп түзетілді.

## Нәтиже
ТЗ-дағы 11 бет, 3 рөл, 4 кесте, PDF-сертификат, 3 Matplotlib графигі, 122 тест, толық құжаттама орындалды; қосымша қала өрісі және QAMQOR дизайны жасалды. Бастапқы архивтегі `run.py` тек «Hello» беті болғандықтан, жоба бұл негізде нөлден жасалды; `run.py` атауы мен `python run.py` іске қосу тәсілі сақталды.
