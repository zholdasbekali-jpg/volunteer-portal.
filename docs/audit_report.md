# Аудит және қорытынды тексеру (v1.0)

Жұмыс 5 кезеңмен жүргізілді. Төменде не тексерілгені және нақты нәтижесі.

## 1. Аудит
- Барлық бет 4 рөлмен (қонақ, ерікті, ұйымдастырушы, әкімші) және 2 экран енімен (1280 және 390 px) автоматты шолып шығылды: 500 қатесі, сынған сурет, JavaScript қатесі, көлденең айналдыру табылмады.
- Табылған олқылықтар: жеке кабинет/профиль жоқ; құпиясөзді ауыстыру жоқ; кіруде құпиясөзді болжаудан қорғаныс жоқ; CSP мен кейбір қауіпсіздік заголовоктары жоқ; прокси артында (Render) https пен IP дұрыс танылмайды.

## 2. Түзетулер
- Фаззинг (20 түрлі «жат» мән × 8 форма × әр өріс + GET параметрлері): өте үлкен сан бар мекенжай (`/events/99999999999999999999`) 500 қатесін берді. Түзетілді: енді 404. Тест қосылды.
- Мәжбүрлі сынақтар (mutation): кодты әдейі бүлдіріп, тесттердің шынымен құлайтыны тексерілді (5 жағдай).
- Браузермен толық жол (20 қадам): тіркелу → кіру → іс-шара құру → тіркелу → қатысуды белгілеу → CSV → сертификат PDF → жария тексеру → кабинет → құпиясөз → шығу → жою. Барлығы жұмыс істейді.

## 3. Дизайн
- Мәзір 9 экран енінде (360…1440 px) × 3 рөл × 4 бет = 108 тіркесімде тексерілді: көлденең айналдыру жоқ; 1200 px-тен төмен мәзір «бургер» болады, жоғарыда бір жолда.
- Жеке кабинет QAMQOR стилінде: компьютер мен телефонда тексерілді.

## 4. Қауіпсіздік
| Тақырып | Шара |
|---|---|
| Құпиясөзді болжау | Email бойынша 5 және IP бойынша 30 сәтсіз әрекеттен кейін 5 минут бұғат (деректер қорында, қайта іске қосқанда сақталады) |
| Сессия | Кіргенде сессия жаңартылады (session fixation); 12 сағаттық мерзім; HttpOnly, SameSite=Lax, https-те Secure |
| Заголовоктар | CSP (скрипт тек өз сайтымыздан), X-Frame-Options, Referrer-Policy, Permissions-Policy (камера тек өзіміз), HSTS (https-те) |
| Кэш | Жеке беттерге `Cache-Control: no-store` |
| Прокси | `TRUST_PROXY=1` болғанда ғана X-Forwarded-* сенімді; әйтпесе жасанды IP еленбейді |
| Рөлдер | Тіркелгенде admin рөлін алу мүмкін емес; рөл мен иелік тексеруі сервер жағында |
| Деректер | Параметрленген SQL, CSRF, автоэкрандау (XSS), CSV-де формула енгізуінен қорғау |
| QR белгілеу | HMAC қол қойылған, 30 с сайын жаңаратын белгі; уақыт терезесі |

Белгілі шектеулер (шынайы): жария `/verify` беті ерікті аты-жөнін көрсетеді (сертификатта да сол); `/verify`-ге жеке шектеу қойылмаған (нөмір кеңістігі үлкен: 2^32); пошта растауы және парольді қалпына келтіру жоқ; нақты хостингте, Windows-та және нақты телефонда толық сынақ жүргізілмеген.
