# Техникалық тапсырма

## 1. Мәселенің сипаттамасы
Еріктілік іс-шараларын ұйымдастырушылар қатысушыларды қолмен (чат, кесте) жинайды: орын саны бақыланбайды, қатысу расталмайды, куәлік беру қолмен жасалады. Эріктілер үшін іс-шараларды бір жерден табу және қатысу тарихын растау мүмкіндігі жоқ.

## 2. Мақсат
Іс-шараларды іздеуге, тіркелуге, қатысуды бақылауға және қатысуы расталған соң PDF-сертификат алуға мүмкіндік беретін веб-портал жасау.

## 3. Пайдаланушылар (рөлдер)
| Рөл | Негізгі мүмкіндіктер |
|---|---|
| Ерікті | Тіркелу/кіру, каталог, іс-шараға тіркелу және бас тарту, өз тіркелімдері мен қатысу мәртебесін көру, сертификат жүктеу |
| Ұйымдастырушы | Өз іс-шараларын құру, өңдеу, тоқтату, жою; тіркелген эріктілер тізімі; қатысуды растау; өз статистикасы |
| Әкімші | Барлық пайдаланушылар (рөлін өзгерту, жою), барлық іс-шаралар мен тіркелімдер, платформа статистикасы |

## 4. Технологиялар
Python 3.11+ (әзірлеу Python 3.13-те тексерілді), Flask, Flask-Login, SQLite, Werkzeug, Jinja2, Bootstrap 5, ReportLab, Matplotlib, pytest, pytest-cov.

Интерфейс пен сертификат QAMQOR волонтерлік жобасының стилінде: қою жасыл (#103309), алтын (#d0b470), ақшыл бежевый фон. ## 7. Шектеулер мен қабылданған шешімдер
- Қатысуды ұйымдастырушы кез келген уақытта белгілей алады (күтіп отырудың қажеті жоқ, көрсету ыңғайлы болу үшін).
- Іс-шара құру кезінде күні болашақта болуы керек; өңдегенде шектеу жоқ.
- Бас тарту тіркелімді жояды; мәртебесі «Қатысты/Қатыспады» белгіленген тіркелімнен бас тартуға болмайды.
- Қатысу «Қатысты»-дан басқа мәртебеге ауысса, берілген сертификат жойылады.
- Сертификатты тек иесі жүктей алады (әкімші де емес).
- Хабарландыру (email) және құпиясөзді қалпына келтіру жүзеге асырылмаған.
