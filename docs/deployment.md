# Интернетке жариялау (https)

Мақсат: сайт кез келген телефоннан ашылсын, сканер камерасы жұмыс істесін, QR басқа құрылғыда ашылсын. Камера тек `https://` арқылы жұмыс істейді.

## Нұсқа 1: Render.com (қарапайым)
1. Жобаны GitHub-қа жүктеңіз (`.venv`, `instance/`, `generated/` Git-ке түспейді).
2. Render → New → Blueprint → репозиторийді таңдаңыз: `render.yaml` барлығын өзі баптайды.
3. `PUBLIC_URL` айнымалысына сайт мекенжайын жазыңыз (мысалы `https://volunteer-portal.onrender.com`).
4. Бірінші іске қосудан кейін Shell-де: `flask --app wsgi:app create-admin` (немесе `seed-demo` демо үшін).

## Нұсқа 2: PythonAnywhere
Python веб-қосымша → WSGI файлында `from wsgi import app as application`; `pip install -r requirements.txt`; https дайын беріледі.

## Қауіпсіздік айнымалылары
- `TRUST_PROXY=1`: Render сияқты проксидің артында нақты IP мен https дұрыс танылады (`render.yaml`-да қойылған).
- `TZ=Asia/Almaty`: қосымша серверлік уақытты қолданады, Render-де әдепкі UTC (`render.yaml`-да қойылған). Қойылмаса, тіркелу, QR-белгілеу терезесі мен «өтті» мәртебесі 5 сағатқа қате ауысады.
- `SESSION_COOKIE_SECURE=1`: кукилер тек https арқылы жіберіледі (`render.yaml`-да қойылған; https-сіз жергілікті іске қосуда қоймаңыз).

## Маңызды ескерту
- Тегін жоспарларда файлдық жүйе уақытша болуы мүмкін: SQLite деректері мен PDF-тер қайта іске қосқанда жоғалады. Демо үшін `seed-demo` қайта жүргізіледі; тұрақты сақтау үшін диск қосу немесе PostgreSQL-ге көшу керек (финалға жоспар).
- Бұл нұсқаулық нақты хостингте әлі тексерілген жоқ: орналастырғанда алдымен `/`, `/verify` беттерін ашып, камераны телефонда тексеріңіз.
- `SECRET_KEY` міндетті түрде өз мәніңіз болсын; репозиторийге жазбаңыз.
