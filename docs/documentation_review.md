# Құжаттаманы тексеру ескертпелері

Бұл құжат `VolunteerPortal_v2.2.zip` архивіндегі ескі мәтін мен кодтың арасындағы табылған айырмашылықтарды тіркейді.

- README бұрынғы мазмұнды қайталап, 204 тест деп көрсеткен. Ол қысқартылып, v2.1 өзгерістер журналындағы 338 passed / 1 skipped көрсеткішіне және v2.2 функцияларына сәйкестендірілді.
- `docs/user_manual.md` және `docs/demo_checklist.md` ішіндегі әкімші демо-паролі қате болған. `app/seed.py` бойынша әкімші — `Admin12345`, ұйымдастырушы мен еріктілер — `Demo12345`. Демо тіркелгілер тек дерекқорда пайдаланушылар жоқ кезде жасалады.
- `docs/test_report.md` ішіндегі кестелер 2026-11-12 күнгі 204 passed тарихи өлшемін береді. Кейінгі changelog 338 тест және 1 skip көрсетеді. Архивті дайындау кезінде тесттер қайта орындалмады.
- `docs/roadmap.md` ішіндегі мерзімдер мен v2.0 күйі — бастапқы жоспардың тарихи деректері; қазіргі релиз күйі емес.
- `docs/database_design.md`-ке v3 қосқан кестелер мен бағандар енгізілді: күту тізімі, таңдаулылар, пікірлер, аудит журналы, кіру шектеулері, санат, тіл және ұйымдастырушыны мақұлдау.
- README әзірлеушілер тізімінде Данаға берілген GitHub тіркелгісі көрсетілді.

Қалған функциялар мен нұсқа мәліметтерінің негізгі дереккөзі — `CHANGELOG.md` және кодтағы іске асыру.
