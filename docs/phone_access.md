# Телефоннан сайтқа кіру

## 1. Бір Wi-Fi желісінде (компьютерде сервер жұмыс істеп тұр)
1. Компьютер мен телефон бір Wi-Fi желісінде болсын.
2. Компьютерде серверді барлық құрылғыларға ашып іске қосыңыз:
   - **PowerShell:** `$env:HOST="0.0.0.0"; python run.py`
   - **cmd:** `set HOST=0.0.0.0` содан кейін `python run.py`
   - **Termux/Linux:** `HOST=0.0.0.0 python run.py`
3. Компьютердің IP-мекенжайын табыңыз: Windows-та `ipconfig` (IPv4), Linux/Termux-та `hostname -I`. Мысалы `192.168.1.5`.
4. Телефон браузерінде ашыңыз: `http://192.168.1.5:5000`.
5. Бірінші рет Windows брандмауэрі рұқсат сұраса, «Рұқсат ету» басыңыз.

**Ұйымдастырушы экранын сол мекенжай арқылы ашыңыз** (`http://192.168.1.5:5000/...`): QR-дағы сілтеме сұрау келген мекенжайдан жасалады, сондықтан ерікті телефоны оны ашады. `localhost` арқылы ашсаңыз, QR басқа құрылғыда жұмыс істемейді.

## 2. Телефонның өзінде сервер (Termux)
`pkg install python`, жоба папкасына кіріп `pip install -r requirements.txt`, содан кейін `python run.py`. Браузерде `http://127.0.0.1:5000`.

## 3. Интернет арқылы (https)
Сайтты Render/PythonAnywhere-ге шығарыңыз: `docs/deployment.md`. Сонда сайт кез келген желіден ашылады.

## Камера туралы
- Сайттағы сканердің камерасы тек `https://` немесе `localhost` арқылы жұмыс істейді. `http://192.168...` бетінде оны браузер бөгейді.
- Сондықтан Wi-Fi арқылы тексергенде **телефонның өз камерасын (Camera қолданбасы)** қолданыңыз: QR-ды көрсетсеңіз, сілтеме ашылады. Не болмаса сканер бетінде «фото жүктеу» әдісін қолданыңыз.
